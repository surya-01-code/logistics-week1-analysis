# Logistics Week 1 — Strategic Planning and Data Exploration

## Project
Data-Driven Inventory and Delivery Route Optimization

## Objective
Develop a reproducible Python workflow for logistics KPI measurement, predictive analysis,
customer/route segmentation and constrained delivery-resource optimization.

## Workflow
Data Collection -> Data Cleaning -> KPI/EDA -> Feature Engineering -> Regression ->
Clustering -> Optimization -> Evaluation -> Decision Support

## Important note
The Week 1 report is a strategic planning deliverable. It does **not** claim completed
operational results. Numerical results should only be added after the underlying dataset
has actually been analysed.

## Suggested public data
- U.S. DOT Bureau of Transportation Statistics Freight Analysis Framework (FAF6):
  https://www.bts.gov/faf
- Last-mile delivery optimization dataset:
  https://zenodo.org/records/15310106

## Files
- `analysis_plan.py` — starter Python workflow and pseudocode
- `requirements.txt` — suggested Python packages
- `README.md` — project documentation
